FANGTUO EMOTIONAL FILM / 01

把今天，
先放妥。

从现实世界的疲惫，到一个能够承接情绪的柔软空间。

CREATIVE STATEMENT

情绪不必立刻被解决。
它可以先被看见、被接住，然后慢慢放妥。

01 / CHARACTER DEVELOPMENT

先让主人公真实存在

通过三视图、面部、服装与随身道具，锁定人物在所有镜头中的身份一致性。

02 / COMPANION IP

现实人物与
情绪保管员

真人主人公负责承载现实压力，放妥 IP 负责接住情绪。两套角色采用统一的暖灰、米白与柔光视觉体系。

03 / EMOTIONAL OBJECT

情绪球是故事的视觉线索

统一材质、尺度与弱发光逻辑，用颜色区分疲惫、温暖、想念、愤怒与焦虑。

04 / SCENE & LIGHTING

光线替情绪完成叙事

01 下班

拥挤人潮与夕阳，把疲惫留在现实世界。

02 傍晚

主人公回到房间，暖光尚未完全消失。

03 深夜

冷蓝夜色压低情绪，放妥空间由此开启。

04 清晨

同一空间重新被自然光照亮。

05 / FANGTUO WORLD

从现实，进入柔软的情绪空间

现实场景采用克制、低照度的光线；进入放妥空间后，材质变得柔软，情绪球成为唯一鲜明的色彩。

06 / PRODUCTION WORKFLOW

从设定到成片

复杂的生成节点被整理为一条可阅读的制作路径。

  1. 01角色统一
  2. 02场景生成
  3. 03分镜设计
  4. 04图生视频
  5. 05镜头衔接
  6. 06剪辑成片
07 / FINAL EDITING

剪辑与成片

把生成镜头、节奏、声音和片名字卡整理为完整的情绪短片。
